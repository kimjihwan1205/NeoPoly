# NeoPoly Project Rules

- **Typography**: All text MUST use the **Pretendard** font family.
  - Hero Display: 40px / 52px (700)
  - Page Titles: 28px / 38px (700)
  - Section Titles: 20px / 30px (600)
  - Card Titles: 16px / 24px (600)
  - Default UI: 14px / 24px (400)
  - Metadata: 12px / 18px (400)
- **Colors**:
  - Brand: #E0A12E (Gold)
  - BG: #050505
  - Surface: #141518 (Primary), #181A1F (Secondary)
  - Border: #2A2E36 (Primary), #1F2329 (Soft)
- **Design Mood**: Maintain the dark, cinematic "Neo-Poly" aesthetic (Dark backgrounds, luxury tool feel).
