# NeoPoly 2차 QA 및 통합 개선 기록

1차 결과: [1차 QA](./2026-09-12-qa-round-1.md). 이번 범위는 보드 → 노트 편집 → AI 정리 → 레퍼런스 수집 → 프로젝트 이어가기 → 콘텐츠 관리의 데이터 연결이다. 실제 AI·인증·결제·메시지 서버 구축과 배포는 제외한다.

## 통합 수정 순서

1. 저장 공통 처리: 빈 목록 보존, 동일 탭/다른 탭 동기화, 실패 안내.
2. 보드/노트/수집: 실제 저장, 공통 데이터 사용, 그룹 유지·되돌리기, 정확한 휴지통 동작.
3. 프로젝트/콘텐츠/프로필: MVP에서 제공 가능한 저장·검색·필터 연결.
4. 공통 UX: 모달 포커스·스크롤, 화면 폭, 검색/돌아가기, 미연동 기능의 시연 안내.
5. 타입 검사·단위 테스트·빌드와 다크/라이트/모바일 회귀 검증.

실제 전송·클라우드 동기화·AI 이미지 이해·결제·인증은 로컬 기능과 구분해서 안내한다. 전체 QA 발견 항목을 모두 제품 수준으로 구현했다는 의미는 아니다. 완료/잔여 상태는 검증 후 별도 통합 결과 문서에 기록한다.
